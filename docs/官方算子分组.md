# 官方算子分组

用户侧算子库按分组树展示。自研算子要出现在某一分组下，需在定义态把 **tag** 配成**从一级分组到目标分组的 `name` 路径**（逗号分隔）。

## 怎么配 tag

以平台分组定义中的这一段为例：

```xml
<group name="input" opType="Input">
    <i18ns en_US="input" zh_CN="输入"/>
    <group name="stream" opCats="stream">
        <i18ns en_US="stream" zh_CN="文件"/>
    </group>
    <group name="db" opCats="db">
        <i18ns en_US="db" zh_CN="数据库"/>
    </group>
    ...
</group>
```

| 想展示在 | tag 配成 |
|----------|----------|
| 输入 | `input` |
| 输入 / 文件 | `input,stream` |
| 输入 / 数据库 | `input,db` |

规则：

1. 取分组树上每一级的 **`name`**（不是中文显示名，也不是单独拿 `opCats` 当 tag）
2. 从一级分组拼到你要挂靠的那一级，中间用英文逗号连接
3. 同名子分组挂在不同一级下，tag 不同：例如 `input,db` 与 `output,db` 不是同一处

下面按「界面路径 → tag」列出当前官方分组（整理自 `operatorGroups.xml`；已注释未启用的节点不列）。`opType` / `opCats` 仅作对照，**配 tag 以 `name` 路径为准**。
